# StudyOS

Live: https://dev-sohail.github.io/StudyOS/

Single-file course management app — list and map/roadmap views, YouTube playlist import, flashcards with SRS, learning time tracking, transcripts, notes, and Namaz prayer times. No build step or backend required. Everything is stored in your browser.

## Features

- Course builder: modules, lessons, drag-to-reorder, auto-save
- List & map/roadmap course views
- YouTube chapter & duration fetching
- Playlist import from YouTube
- Flashcards with spaced repetition
- Streak tracking, weekly forecasts, time analytics
- PDF/web/reading/practice/quiz lesson types
- Transcript viewer & exporter
- Namaz prayer times with reminders
- Export/import courses as JSON

## Usage

Open `index.html` in any modern browser. No installation needed.
